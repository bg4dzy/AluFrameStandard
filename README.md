# FreeCAD AluFrame Standard Models Library

FreeCAD AluFrame 开源铝型材标准参数化模型库 | Open Source Parametric Aluminum Frame Library

项目持续建设中 | Under Continuous Construction

## 📖 项目介绍 | Intro
本项目是FreeCAD 原生参数化模型库，专注国标/欧标工业铝型材及全套配套配件建模。所有模型均为通用工业标准件，规格公开统一，可直接在淘宝等主流电商平台采购实物，遵循行业标准、可参数化修改、可直接装配复用，适用于创客机架、开源硬件、小型自动化结构设计。

This is a native FreeCAD parametric model library focused on national and European standard industrial aluminum profiles and complete supporting accessories. All models are universal industrial standard parts with unified public specifications, and physical products can be purchased on mainstream e-commerce platforms such as Taobao. The models are fully parametric, editable and assembly-ready, suitable for maker racks, open-source hardware and small automated structural designs.

**项目进展：** 初期建设中，持续迭代 2020/3030/4040 系列铝型材及紧固件、连接件、防护配件标准化模型。

**Project Progress:** Under initial construction. Standardized models of 2020/3030/4040 series aluminum profiles, fasteners, connectors and protective accessories are continuously being updated and optimized.

## 🔌 依赖插件 | Required & Optional Addons
所有模型均在FreeCAD 1.1.0的后续版本中建模，为了能在装配工作平台使用，需提前安装以下插件：
All models are created based on FreeCAD 1.1.0 and later versions. To work properly in the assembly workbench, please install the following addons in advance.
### ✅ Core Required Addons (Mandatory)
- EasyProfileFrame
铝型材快速建模工作台，支持框架拼接、裁切与BOM导出。
Rapid profile modeling, frame splicing, cutting and BOM generation.
### ⚙️ Optional Enhancement Addons (Efficiency Improvement)
- Fasteners
标准螺丝、螺母、垫片紧固件库，统一装配标准。
Standard bolt, nut and washer library for standardized assembly.
